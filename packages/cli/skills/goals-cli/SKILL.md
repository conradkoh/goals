# Goals CLI

This is a stub. The full, versioned guidance ships with the installed CLI and is always up to date.

Run `goals skill activate` and follow what it prints. It needs no login and makes no network call.

If `goals` is not found, install it with `npm i -g goals-cli` (or use `npx goals-cli skill activate`).
